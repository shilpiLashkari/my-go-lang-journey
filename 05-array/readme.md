# Day 05: Array (Arrays, Slices, Maps)

In this practice, I'm exploring the core basic data structures in Go.

## Concepts Covered
- **Arrays**: Fixed-sized collections of elements of the same type.
- **Slices**: Dynamically-sized, flexible view into the elements of an array.
- **Maps**: Unordered collection of key-value pairs, similar to dictionaries in Python or objects in JavaScript.

## Code Example
You can run the examples by executing:

```bash
go run main.go
```
