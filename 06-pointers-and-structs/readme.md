# Day 06: Pointers & Structs

Practice Go pointers and defining/using structs.

## Concepts Covered
- **Pointers**: Storing memory addresses and dereferencing them using `&` and `*`.
- **Structs**: Collections of fields, used to represent records or objects.
- **Pass by Reference**: Using pointers to modify struct data within functions.

## How to Run
```bash
go run main.go
```
